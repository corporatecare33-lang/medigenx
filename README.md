# MediGenX - Medical Equipment & Healthcare Solutions

A modern, responsive website for MediGenX - a leading provider of advanced medical equipment and comprehensive healthcare solutions.

## 🏥 About

MediGenX is a global leader in delivering cutting-edge medical equipment and comprehensive healthcare solutions. We specialize in:

- **LinaTech VenusX Radiotherapy Machines**
- **Robotic Medical Equipment**
- **Radiology & Imaging Systems**
- **Medical Consumables**
- **Hospital Management Consultancy**
- **After-Sales Support & Maintenance**

## ✨ Features

- 🎨 Modern, professional design with Tailwind CSS
- 📱 Fully responsive (Mobile, Tablet, Desktop)
- 🛒 E-commerce functionality for medical consumables
- 🗺️ Integrated Google Maps for location
- 📧 Contact forms and inquiry system
- 🔍 Product filtering and search
- 🛍️ Shopping cart with checkout flow
- ⚡ Fast and optimized performance
- 🎯 SEO-friendly structure

## 🚀 Tech Stack

- **React** - Frontend framework
- **React Router** - Navigation
- **Tailwind CSS** - Styling
- **Lucide React** - Icons
- **Vite** - Build tool

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/corporatecare33-lang/medigenx.git
cd medigenx
```

2. Install dependencies:
```bash
npm install
```

3. Start development server:
```bash
npm run dev
```

4. Build for production:
```bash
npm run build
```

5. Preview production build:
```bash
npm run preview
```
